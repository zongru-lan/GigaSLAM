# generated_metric_width

This directory is reserved for configs generated by experiment scripts.
It is not the canonical place for maintained configs.

Current maintained configs live under `configs/railway/rowtrack350/`:

- `template.yaml`: frozen rowtrack350 mainline baseline template.
- `scenes/*.yaml`: per-scene dataset path overrides.
- `experiments/*.yaml`: named, maintained experiment configs.
- `baselines/*.csv`: frozen cross-scene regression baselines.

The two `depthdiag_*.yaml` files here are compatibility shims for older commands only; prefer `configs/railway/rowtrack350/experiments/depthdiag.yaml` and `configs/railway/rowtrack350/experiments/depthdiag_scene16.yaml`.

One-off generated configs, dry-runs and retry configs from 2026-05-26 were archived to `configs/archive/generated_metric_width_runs_20260526/`.
